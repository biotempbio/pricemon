# BIO price-monitor

Облачный агент мониторинга цен UNOX и CARBOMA. Работает на Timeweb VM, хранит
рабочие наблюдения в PostgreSQL и передаёт снимки в BIO Product Center.

## Проверка перед доставкой

```bash
python check.py
python -m unittest -v
```

`check.py` обязателен: он проверяет наличие критических функций, соответствие
`RUN_OK` диспетчеру команд, синтаксис и вызовы неизвестных имён.

## Надёжность

- Командная метка создаётся только после успешного завершения команды.
- Исключения доходят до systemd и записываются в `last-<command>.txt`.
- Whitegoods не обходится: капча не автоматизируется.
- Себестоимость и дилерские цены не публикуются наружу.
- Production-цены меняет только BIO Product Center после защитных проверок.

Локальные секреты хранятся только в `/opt/pricemon/.env` и не коммитятся.
